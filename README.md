# argand-fold
Visualizer showing how complex functions warp the argand-gauss plane

## Features
The script is now able to show an animation of the warping the complex function does
The complex function is defined inside the ```f(z)``` function

> [!important]
> This is simply a dumb test version
> The complete version will have multiple ways of showing the complex plane, a way to export gifs and also a way to detect and plot a new function live while running the script
